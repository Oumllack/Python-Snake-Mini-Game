# Jeu Snake avec PyGame

Un jeu Snake classique créé avec PyGame.

## Installation

1. Assurez-vous d'avoir Python installé sur votre système
2. Installez les dépendances requises :
```bash
pip install -r requirements.txt
```

## Comment jouer

1. Lancez le jeu :
```bash
python snake_game.py
```

2. Contrôles :
- Flèches directionnelles pour déplacer le serpent
- Mangez la nourriture (carrés rouges) pour grandir et augmenter votre score
- Évitez les murs et votre propre corps

## Règles du jeu

- Le serpent grandit à chaque fois qu'il mange de la nourriture
- Le jeu se termine si le serpent touche un mur ou son propre corps
- Votre score augmente de 1 à chaque fois que vous mangez de la nourriture
