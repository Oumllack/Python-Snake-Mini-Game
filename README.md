# Python Collection Game

A fast-paced collection game built with PyGame where you control a green square to collect red targets within a time limit.

## 🎮 Game Features

- 60-second time limit
- Score tracking
- Smooth controls
- Random target spawning
- Restart functionality
- Clean, modern interface

## 🎯 How to Play

1. Use arrow keys to move the green square
2. Collect the red targets to score points
3. Each collected target gives you 1 point
4. Try to get the highest score within 60 seconds
5. The game ends automatically when time runs out
6. Click "Replay" to start a new game

## 🛠️ Installation

1. Make sure you have Python 3.11+ installed
2. Clone this repository:
```bash
git clone https://github.com/Oumllack/Python-Snake-Mini-Game.git
cd Python-Snake-Mini-Game
```

3. Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

4. Install required packages:
```bash
pip install -r requirements.txt
```

## 🚀 Running the Game

```bash
python snake_game.py
```

## 🎯 Controls

- ↑ (Up Arrow): Move up
- ↓ (Down Arrow): Move down
- ← (Left Arrow): Move left
- → (Right Arrow): Move right

## 🏆 Scoring

- Each red target collected = 1 point
- Score is displayed in the top-left corner
- Time remaining is shown in the top-right corner
- Final score is displayed when the game ends

## 🛠️ Technical Details

- Built with PyGame 2.5.2
- Python 3.11+
- Window size: 800x600 pixels
- Target size: 20x20 pixels
- Player speed: 30 pixels per frame
